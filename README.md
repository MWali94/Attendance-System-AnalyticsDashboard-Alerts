# Attendance Management System

A responsive web-based Attendance Management System designed for educational institutes to efficiently manage student attendance, monitor performance, and improve communication between staff, students, and parents.

## Features

### Staff Panel
- Mark and manage student attendance records.
- Track low-attendance and at-risk students automatically.
- Receive alerts and notifications for students with poor attendance.
- View attendance statistics and reports.
- Manage student records and class information.

### Student & Parent Access
- Students and parents can check attendance instantly without creating an account.
- Search attendance records using:
  - Student Name
  - Roll Number
- Simple and user-friendly interface for quick access to attendance information.

## Key Highlights
- Responsive and easy-to-use design.
- Secure attendance tracking system.
- Fast attendance lookup functionality.
- Helps institutions identify attendance issues early.
- Built as a scalable foundation that can be expanded with additional features such as:
  - SMS/Email notifications
  - Performance analytics
  - Timetable integration
  - Role-based dashboards

## Technologies Used
- PHP
- MySQL
- HTML5
- CSS3
- JavaScript

## Purpose
This project was developed as a complete attendance management solution that simplifies attendance tracking while improving transparency and communication between teachers, students, and parents.
